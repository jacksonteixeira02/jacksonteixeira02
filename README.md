✫・ Sobre mim

Olá! Eu sou Jackson Teixeira, estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor em formação.

Minha trajetória na programação começou através do estudo de Java, e desde então venho construindo minha base em diferentes áreas do desenvolvimento de software, principalmente backend, banco de dados e desenvolvimento Web.

Gosto de aprender colocando a teoria em prática. Por isso, boa parte dos meus estudos acaba se transformando em pequenos projetos, sistemas acadêmicos ou experimentos para entender melhor determinada tecnologia.

Atualmente, meu principal foco está em Java e desenvolvimento de aplicações, enquanto continuo expandindo meus conhecimentos em banco de dados, Web, APIs e ferramentas utilizadas no desenvolvimento profissional.

«Meu objetivo é evoluir constantemente, transformar conhecimento em experiência e construir soluções cada vez melhores.»
